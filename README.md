# 포켓몬카드 거래 기반 커뮤니티 프로토타입

[프로토타입 열기](https://jaypark-pd.github.io/bunjang-community-review/prototype/)

거래 경험으로 연결된 포켓몬카드 커뮤니티의 HTML 프로토타입입니다.

- 이야기 피드, 거래 카드 첨부, 댓글과 반응
- 상품 보기 / 거래내역 전환, 전체 / 내 거래 / HIT 필터
- KREAM HIT 기획전에서 확인한 카드 4종과 이미지

거래 금액·날짜·상태·이용자는 가상 데이터입니다. 작성한 글과 반응은 해당 브라우저에만 저장됩니다.

카드 이미지 출처는 `research/hit-card-sources.json`, 대화 재구성 출처는 `research/content-sources-and-history-view.md`에 기록했습니다.

별도의 빌드 과정 없이 정적 서버에서 `prototype/index.html`을 열면 됩니다.
